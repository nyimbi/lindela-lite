# Internationalisation

Lindela Lite supports 10 locales. Catalogs live in `public/i18n/*.json`. The server serves them at `/i18n/<locale>.json`.

## Supported locales

| Code | Language | Coverage | Surface priority |
|---|---|---|---|
| `en` | English | Full | All surfaces |
| `sw` | Swahili | Full | All surfaces |
| `ar` | Arabic (RTL) | Full | All surfaces |
| `so` | Somali | Full | CHW, Focal Point |
| `din` | Dinka | Partial | CHW |
| `km` | Karimojong | Partial | CHW |
| `nk` | Ngakarimojong | Partial | CHW |
| `fr` | French | Partial | Operator Console, CO Dashboard |
| `pt` | Portuguese | Partial | Operator Console, CO Dashboard |
| `am` | Amharic | Partial | Operator Console |

"Full coverage" means every i18n key present in the English catalog has a translation. "Partial" means some keys fall back to English.

## Re-adding deferred locales

French (`fr`), Portuguese (`pt`), and Amharic (`am`) were initially deferred to `public/i18n/_deferred/` in Phase 1. They are re-added in Phase 2 and listed in `SUPPORTED_LOCALES` in `src/i18n.js`. Locale selectors in all HTML surfaces include these three options.

## Adding a new locale

1. Create `public/i18n/<code>.json` with at minimum the keys from `en.json`.
2. Add the code to `SUPPORTED_LOCALES` in `src/i18n.js`.
3. Add an `<option value="<code>">` entry to the locale selector in each surface's `index.html`.
4. Mark coverage in this table.

## RTL

Only Arabic (`ar`) currently triggers RTL layout. The `isRtl(locale)` helper in `src/i18n.js` returns `true` for `ar`. Surfaces that call `isRtl` apply `dir="rtl"` to the root element.

## CHW surface priority

The CHW surface is highest priority for field languages (Somali, Dinka, Karimojong, Ngakarimojong). All 10 locales are available in the locale selector but field-language coverage is best-effort beyond the four bidding languages.
